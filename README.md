# Java OOP Practicals — 5th Semester

This repository contains 10 Java programs based on Object-Oriented Programming (OOP) practical assignments for the 5th semester of B.Tech CSE.

## 📚 Practicals List

| No. | Practical Name | Concepts Covered |
|---|---|---|
| 1 | Classes and Objects | Classes, objects, constructors, methods |
| 2 | Single, Multilevel, and Hierarchical Inheritance | Inheritance using `extends` |
| 3 | Hybrid and Multiple Inheritance Using Interfaces | Interfaces, `implements`, hybrid inheritance |
| 4 | Method Overloading and Method Overriding | Compile-time and runtime polymorphism |
| 5 | Simulating Operator Overloading Using Methods | Complex numbers and object-based addition |
| 6 | Default, Parameterized, and Copy Constructors | Constructor types and copying objects |
| 7 | Object Lifecycle and Garbage Collection | Object references, garbage collection, destructors |
| 8 | Constructor Overloading | Multiple constructors with different parameters |
| 9 | `this` Keyword, Constructor Chaining, and Static Members | `this`, `this()`, static variables and methods |
| 10 | Encapsulation Using Getters, Setters, and Validation | Data hiding, access modifiers, validation |

## 🛠️ Requirements

- Java Development Kit (JDK) installed
- A code editor such as Visual Studio Code
- Basic knowledge of Java programming
- Git and GitHub (for version control)

## ▶️ How to Run the Programs

### Step 1: Check Java installation

Open a terminal and run:

```bash
java -version
javac -version
```

### Step 2: Compile a program

For example, to compile Practical 1:

```bash
javac Practical1.java
```

### Step 3: Run the program

```bash
java Practical1
```

Repeat these steps for any other practical by replacing `Practical1` with the corresponding class and filename.

**Note:** The public class name must match the Java filename exactly.

## 🎯 Learning Objectives

- Understand classes, objects, and constructors.
- Implement different types of inheritance.
- Use interfaces to achieve multiple inheritance-like behavior.
- Understand method overloading and overriding.
- Perform operations on user-defined objects.
- Explore object lifecycle and garbage collection.
- Implement constructor overloading and constructor chaining.
- Understand the `this` keyword and static members.
- Apply encapsulation and input validation.
